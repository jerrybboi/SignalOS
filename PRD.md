# SignalOS PRD

## One-line pitch
SignalOS is an AI market-decision agent that detects unusual Binance market activity, investigates what is driving it, builds a falsifiable market thesis, and checks risk before the user acts.

## Core workflow
**Radar → MoveLens → Thesis → Guard**

## V1
- Home
- Radar
- Investigation / MoveLens
- Thesis
- Guard
- Binance Agent OS integration
- Responsive interface
- Public deployment
- Public GitHub repository
- $0 required infrastructure

## Hard constraints
- $0 build cost for the core demo
- No paid AI API required
- No funded trading account required
- No fabricated Binance market observations
- Human retains control over any future execution
